About pbr2rad

What it does

Turns a PBR texture set — colour, roughness, metalness and normal maps from ambientCG, Poly Haven, or your own files — into a ready-to-use Radiance material: the images as HDR/.dat data, the .cal projection, and a plastic/metal primitive with calibrated reflectance, zipped together with a preview render.

Why

Photoreal textured materials in Radiance are usually expert-mode work: hand-writing .cal functions, converting images to HDR, guessing at reflectance. pbr2rad does that conversion for you, so you get physically plausible, textured materials without the ritual — and it reports the visible reflectance so the result stays defensible for lighting analysis.

Intended workflow · ClimateStudio

Pick or upload a texture set → tune it against the reference render → Download the .zip → drop the material folder into ClimateStudio's custom materials library → assign it in Rhino from the ClimateStudio material picker. The output is plain Radiance, so it also works in any other Radiance-based tool.

Status

pbr2rad is an experiment by Jeff Thompson, not a Solemma product. It has been built with approval for use from the ClimateStudio developers, who have accommodated pbr2rad materials on their side. Textures are CC0 from ambientCG and Poly Haven. Questions or ideas: jt@thompsonjeff.com.
